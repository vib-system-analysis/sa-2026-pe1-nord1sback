# 6. Глоссарий

| Термин | Определение |
|---|---|
| Система «как есть» | Люди, вещи и действия, с помощью которых задача решается до внедрения нового продукта |
| Эпизод выбора | Один конкретный случай поиска и выбора одежды для повода |
| Граница системы | Разделение того, что выполняет задачу внутри системы, и внешних факторов, которые на неё влияют |
| Среда | Внешние обстоятельства эпизода, например повод, погода и время выхода |
| Наблюдаемый результат | Зафиксированный факт, по которому можно проверить достижение цели, например длительность выбора или своевременность выхода |
| Рабочее допущение | Временное предположение, которое требуется проверить наблюдением |
| Полевое наблюдение | Запись конкретных действий в реальном эпизоде с контекстом и неожиданным результатом |
