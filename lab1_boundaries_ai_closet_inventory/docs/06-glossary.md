# 6. Глоссарий

| Термин | Определение |
|---|---|
| Граница системы | Разделение ответственности разрабатываемой системы и внешних участников/систем |
| Каталог гардероба | Структурированный список вещей пользователя и их атрибутов |
| Атрибут вещи | Характеристика предмета: категория, цвет, сезон и т. п. |
| AI-провайдер | Внешний сервис или модель, выполняющая распознавание или генерацию рекомендаций |
| Рекомендация комплекта | Предложенный набор вещей из каталога, подходящий под указанные критерии |
| Подтверждённый атрибут | Значение, проверенное пользователем или иным предусмотренным правилом |
| Внешняя интеграция | Система вне границы приложения, с которой оно обменивается данными |
| Допущение | Временное предположение, которое нужно проверить |
| Открытый вопрос | Неопределённость, требующая ответа до окончательного проектного решения |
