# Лабораторная работа №2 — Структура и дерево целей

**Тема:** система повседневного выбора одежды из собственного гардероба.

## Цель работы

Разложить существующую систему выбора одежды двумя способами, построить измеримое дерево целей, выявить конфликт и определить проседающую ветку по имеющимся наблюдениям.

## Связь с лабораторной №1

Лабораторная №1 описывает существующий процесс выбора одежды без цифрового помощника и фиксирует три наблюдавшихся эпизода. Лабораторная №2 продолжает анализ этой же системы; будущее приложение не включается в ее состав.

В трех исходных эпизодах выбор занимал 7–18 минут (медиана — 9 минут); одновременно уложиться в 10 минут и выйти по плану удалось в одном эпизоде из трех. Это малая исходная выборка, по которой нельзя обобщать результаты на другие ситуации и людей.
